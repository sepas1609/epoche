# Epoché (Ἐποχή)
> *The Local-First Research Submission & Peer-Review War Room*

**Epoché** (pronounced *eh-poh-KAY*, from ancient Greek ἐποχή: *"suspension of judgment"*) represents the exact state of a scientific manuscript under peer review — an intellectual period of deliberation, scrutiny, and pending verdict.

---

### Core Philosophy
1. **Zero-Knowledge Academic Privacy**: All drafts, reviewer remarks, and paper metadata remain strictly inside client-side browser storage (IndexedDB / Web Crypto). No university IP leaks, no cloud harvesting.
2. **Team Synchronization without Inboxes**: Solves the single-corresponding-author bottleneck by enabling collaborative delegation of reviewer comments and revision deadlines.
3. **Anti-Deadline Amnesia**: Eliminates post-submission memory fade with countdown widgets, Overleaf/GitHub commit anchoring, and 48-hour revision sprint alerts.
4. **100% Free & Open Source**: Deployable seamlessly on Cloudflare Pages, Vercel, or GitHub Pages at zero hosting cost.
